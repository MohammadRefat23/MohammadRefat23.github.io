## Code

Public repositories behind these projects. Most are cleaned reconstructions of research code, each with a README describing the method.

- [**StarryAtmospheres**](https://github.com/MohammadRefat23/StarryAtmospheres): spherical-harmonic inversion of rotational light curves for brown-dwarf and giant-exoplanet atmospheres, built on `starry`.
- [**jhelum-stellar-stream**](https://github.com/MohammadRefat23/jhelum-stellar-stream): chemical-abundance analysis and visualization for stars in the APOGEE Jhelum fields, reconstructed from public data.
- [**tigress-metallicity-correlations**](https://github.com/MohammadRefat23/tigress-metallicity-correlations): two-point statistics of metallicity fluctuations in a TIGRESS simulation of the star-forming ISM.
- [**VGC metagame analysis**](https://github.com/MohammadRefat23/MohammadRefat23.github.io/tree/main/analysis): SQL and Python comparison of monthly Smogon usage reports, with the import script and tests in this site's repository.

All repositories are on [GitHub](https://github.com/MohammadRefat23).
