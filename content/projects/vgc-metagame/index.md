I enjoy competitive Pokémon VGC and exploring how metagame trends change over time. This interactive network uses a periodically updated snapshot of Pokémon Champions data.

Each node represents a highly ranked Pokémon. Node size reflects overall ranking, and connections show teammate affinity: stronger connections indicate Pokémon that rank more highly among one another's commonly used teammates. Because the visualization uses periodic snapshots, it also provides a record of how the metagame changes.
